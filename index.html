Las dos versiones de cada proyecto

  • Ver resuelto — el proyecto terminado y comentado línea por línea. Sirve como referencia mientras explicas y como solución para entregar después de la clase.
  • Plantilla de clase — la misma página con el HTML y el CSS ya completos (todos los elementos, ids y clases ya puestos) y el JavaScript por escribir. Cada archivo conserva sus secciones y la explicación del concepto, pero el código se sustituye por instrucciones // TODO (en clase): que indican el nombre de las variables, el id del elemento con el que trabajar y la salida esperada. La página arranca vacía a propósito: se va llenando conforme escribes el código en vivo.

Cómo abrir los proyectos

  1. Los proyectos 01 al 08 y el 11 funcionan con doble clic sobre su index.html.
  2. El 09 y el 10 necesitan un servidor local. La forma más simple es la extensión Live Server de VS Code: clic derecho sobre el archivo → Open with Live Server.
  3. Sin VS Code, desde la terminal y dentro de la carpeta del proyecto: python3 -m http.server 8000 y luego abrir http://localhost:8000.
  4. Recuerda tener abierta la consola del navegador con F12: casi todos los ejemplos también imprimen ahí, además de en el bloque de salida de la propia página.

Cómo está organizado cada proyecto

  • index.html — la página con la teoría y la parte práctica.
  • css/estilos.css — los estilos, también comentados.
  • js/ — un archivo por tema, numerado en el orden en que conviene explicarlo.
  • README.md — guía docente: temas, tiempos por bloque, ejercicios y errores comunes.
  • plantilla-clase/ — la misma estructura, con el JavaScript por completar.

Convenciones de los comentarios

  • // TODO (en clase) — solo en las plantillas: el código que se escribe en vivo.
