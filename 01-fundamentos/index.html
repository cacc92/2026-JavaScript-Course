2 · ¿Qué es JavaScript y dónde se ejecuta?

      

        JavaScript es un lenguaje de programación interpretado que se ejecuta dentro de
        un programa llamado motor. En el navegador Chrome ese motor se llama V8; en Firefox,
        SpiderMonkey. El motor lee tu código y lo va ejecutando línea por línea.
      

      

        

          
HTML

          
Es la estructura: títulos, párrafos, botones. Responde a “qué hay”.

        

        

          
CSS

          
Es la presentación: colores, tamaños, posiciones. Responde a “cómo se ve”.

        

        

          
JavaScript

          
Es el comportamiento: qué pasa al pulsar, calcular o pedir datos.

        

      

      

        Hoy JavaScript también se ejecuta fuera del navegador (en servidores, con Node.js),
        pero en este curso trabajamos siempre en el navegador, que es donde vive el Front End.
      

      

        Ojo: JavaScript y Java son lenguajes distintos, sin relación técnica.
        El nombre fue una decisión comercial de 1995.
      

    


    
    

      
3 · Las 3 formas de incluir JavaScript en HTML


      
a) En línea (inline) — no recomendada

      
El código va dentro de un atributo del elemento HTML.

      
<button onclick="alert('Hola')">Pulsa</button>

      

        Mezcla estructura y comportamiento, no se puede reutilizar y es muy difícil de mantener.
        En la sección 10 hay un botón de ejemplo marcado como “así NO se hace”.
      


      
b) Interna (embebida) — útil solo para pruebas rápidas

      
El código va dentro de una etiqueta <script> del propio HTML.

      
<script>
  console.log('Hola desde un script interno');
</script>


      
c) Externa con defer — la correcta ✅

      
El código vive en su propio archivo .js y el HTML solo lo enlaza.

      
<script src="js/01-variables-y-tipos.js" defer></script>

      
    
        
  • Separa responsabilidades: HTML estructura, JS comportamiento.
    • 
        
  • El navegador puede cachear el archivo y reutilizarlo entre páginas.
    • 
        
  • defer descarga en paralelo y ejecuta cuando el HTML ya está listo.
    • 
        
  • Los scripts con defer se ejecutan en orden, de arriba abajo.
    • 
      

      

        Regla práctica del curso: siempre externa + defer.
      

    


    
    

      
4 · Comentarios y el objeto console

      

        Un comentario es texto que el motor ignora. Sirve para explicar el porqué del código,
        no el qué (el qué ya lo dice el propio código).
      

      
// Comentario de una sola línea

/*
  Comentario de bloque:
  ocupa varias líneas.
*/

      
El objeto console tiene varios métodos, no solo log:

      
    
        
  • console.log() — mensaje normal.
    • 
        
  • console.info() — información.
    • 
        
  • console.warn() — advertencia (amarillo).
    • 
        
  • console.error() — error (rojo).
    • 
        
  • console.table() — dibuja una tabla con arreglos de objetos.
    • 
      

      

        Los colores de warn y error solo se ven en DevTools
        (F12), no en la consola visual de esta página.
      

    


    
    

      
5 · Variables: var, let y const

      

        Una variable es una caja con etiqueta donde guardamos un valor para usarlo después.
        JavaScript tiene tres formas de crear esa caja, y no son equivalentes.

              Nunca en código nuevo
              Si el valor va a cambiar

        Regla del curso: empieza siempre con const. Solo cambia a let
        cuando el propio código te obligue a reasignar. var se queda en el pasado.
      

      

        Cuidado: const significa “no puedo reasignar la caja”,
        no “el contenido es inmutable”. Un objeto declarado con const
        sí puede cambiar por dentro.
      

    


    
    

      
6 · Tipos de datos y typeof

      

        JavaScript tiene 7 tipos primitivos (valores simples e inmutables) y los
        tipos de referencia (objetos, arreglos y funciones).
      

      

        
string
Texto: 'Ana'

        
number
Números: 7, 3.5

        
boolean
true / false

        
undefined
Aún sin valor asignado

        
null
Vacío a propósito

        
symbol
Identificador único

        
bigint
Enteros enormes: 10n

        
object
No es primitivo: es el tipo de referencia (objetos, arreglos, funciones)

      

      

        Las siete primeras tarjetas son los tipos primitivos; la octava,
        object, agrupa los tipos de referencia. La diferencia
        práctica se ve en la consola: un primitivo se copia por valor y un objeto, por referencia.
      

      

        La rareza más famosa del lenguaje: typeof null devuelve "object".
        Es un error de 1995 que no se corrige para no romper millones de páginas.
      

    


    
    

      
7 · Operadores

      

        

          
Aritméticos

          
+ - * / % ** — el % da el resto y ** la potencia.

        

        

          
Asignación

          
= += -= *= /= %= y los incrementos ++ / --.

        

        

          
Comparación

          
== === != !== > < >= <= — siempre devuelven un booleano.

        

        

          
Lógicos

          
&& || ! y el cortocircuito, que evita evaluar de más.

        

        

          
Ternario

          
condición ? siEsVerdad : siEsFalso — un if en una sola línea.

        

        

          
Precedencia

          
El orden en que se resuelven. Ante la duda, usa paréntesis.

        

      

    


    
    

      
8 · Tabla comparativa: == frente a ===

      

        == compara solo el valor y convierte tipos antes de comparar (coerción).
        === compara valor y tipo, sin convertir nada.

              Expresión
              Con ==
              Con ===
              Qué está pasando
            

          
          
            

              5 · '5'
              true
              false
              El texto '5' se convierte al número 5.
            

            

              0 · false
              true
              false
              false se convierte en 0.
            

            

              '' · false
              true
              false
              Ambos se convierten en 0.
            

            

              null · undefined
              true
              false
              Regla especial: solo se parecen entre ellos.
            

            

              null · 0
              false
              false
              null NO se convierte a número al comparar con ==.
            

            

              [] · false
              true
              false
              El arreglo vacío se vuelve '' y luego 0.
            

            

              NaN · NaN
              false
              false
              NaN no es igual ni a sí mismo. Usa Number.isNaN().
            

          
        

      

      

        En la tabla, el punto “·” representa el operador de la columna
        (== o ===). Los resultados exactos se imprimen también
        en la consola visual con console.table().
      

      

        Regla del curso: usa siempre === y !==.
        La única excepción aceptada es valor == null para detectar
        null y undefined a la vez.
      

    


    
    

      
9 · Conversión de tipos y coerción

      

        Explícita: la pides tú con Number(), String(),
        Boolean(), parseInt() o parseFloat().
        Implícita (coerción): la hace el motor por su cuenta cuando mezclas tipos.
      

      
'5' * 2   // 10   -> el * convierte el texto a número
'5' + 2   // '52' -> el + con texto CONCATENA
'5' - 2   // 3    -> el - siempre es aritmético
[] + {}   // '[object Object]'

      

        Todo lo que escribe el usuario en un <input> o en un prompt()
        llega como texto. Si no lo conviertes, '2' + '3' te dará
        '23' en vez de 5.
