01 Condicionales: if, else if, else

Un condicional es una bifurcación en el camino: el programa evalúa una expresión, obtiene true o false, y ejecuta un bloque u otro. Aquí vemos el if simple, la cadena if / else if / else, los condicionales anidados, los valores truthy y falsy, y el operador ternario.

Error clásico de principiante: escribir = (asignar) donde hace falta == o === (comparar). En clase lo veremos en vivo: if (nota = 10) siempre entra, porque asigna y devuelve 10, que es truthy.

02 La sentencia switch


        

          switch compara UN valor contra varios casos posibles. Es la
          herramienta ideal cuando tenemos muchas opciones cerradas (un menú, un día de
          la semana, un código de estado). Veremos case, break,
          default, el peligro del fall-through, un caso donde el
          fall-through es justo lo que queremos, y cuándo conviene más un
          if / else.

03 Bucles: for, while, do...while y familia


        

          Un bucle repite un bloque de código mientras se cumpla una condición. Vamos a
          desmontar el for clásico pieza a pieza, compararlo con
          while y do...while, recorrer arrays y textos con
          for...of, recorrer objetos con for...in, y usar
          break y continue para controlar la repetición desde
          dentro.
        


        

          Bucle infinito: si la condición nunca se vuelve falsa, la pestaña
          se congela. En la sección 13 de js/03-bucles.js lo provocamos
          de forma controlada con un contador de seguridad (el botón de aquí abajo),
          para verlo sin bloquear el navegador.

05 Clasificador de notas interactivo


        

          Escribe una nota del 0 al 10 y pulsa el botón. El mismo problema se resuelve
          dos veces: una con una cadena if / else if / else y
          otra con switch (true). Compara los dos resultados y decide cuál te
          resulta más legible.
        


        

          

            
            
          

          
        


        

          

            Versión if / else if / else
            Escribe una nota y pulsa "Clasificar nota".
          

          

            Versión switch (true)
            Escribe una nota y pulsa "Clasificar nota".
          

        


        

          Buena práctica: el orden de las condiciones importa. Si preguntas
          primero por nota >= 5, un 10 también cumple esa condición y nunca
          llegarías a "Excelente". Siempre de la condición más restrictiva a la más amplia.
