JavaScript moderno (ES6+) y módulos

En este proyecto repasamos a fondo todo lo que el lenguaje ha incorporado desde 2015 (declaraciones, plantillas, destructuring, spread, encadenamiento opcional, generadores…) y damos el salto definitivo: organizar el código en módulos ES nativos, con import y export, tal y como se trabaja hoy en cualquier proyecto profesional de front end.

⚠️ Este proyecto NO funciona abriéndolo con doble clic

Has abierto la página con el protocolo file://. Los módulos ES están sujetos a la política CORS del navegador, que solo permite orígenes http:// o https://. Con file:// el navegador bloquea todos los import y verás la página en blanco de contenido dinámico.

Soluciones (elige una):

  1. Live Server (recomendado en clase). En Visual Studio Code instala la extensión Live Server, haz clic derecho sobre index.html y elige Open with Live Server.
  2. Python. Abre una terminal dentro de esta carpeta y ejecuta python3 -m http.server 8000. Después visita http://localhost:8000.

Los módulos ES todavía no se han cargado

Si este mensaje sigue en rojo después de unos segundos, los import no se resolvieron. Revisa el aviso de arriba y la consola del navegador (F12 → Consola).

05 Parámetros por defecto evaluados en tiempo de llamada

      

        Un detalle que sorprende a quien viene de otros lenguajes: el valor por defecto se calcula
        en cada llamada, no una sola vez al definir la función.

emitirBoleta(1990);                 // falta el folio -> llama a siguienteFolio()
emitirBoleta(3100, 'FOLIO-MANUAL'); // llega el folio -> NO la llama nunca

07 Operadores lógicos de asignación

10 Iterables y Symbol.iterator

      

        Por qué for...of funciona con arrays y strings pero no con objetos planos,
        qué contrato cumple un iterador (next() → { value, done }) y cómo
        implementarlo a mano en un objeto y en una clase.
      


      

        
const rango = {
  [Symbol.iterator]() {
    let actual = 1;
    return { next: () => actual <= 5
      ? { value: actual++, done: false }
      : { value: undefined, done: true } };
  },
};

[...rango]; // [1, 2, 3, 4, 5]


        

          
          
        


        

      

    


    
    

      
11 Funciones generadoras function* y yield

      

        Un generador de identificadores, un generador infinito de Fibonacci que no
        cuelga el navegador, delegación con yield*, envío de valores con
        next(valor) y un recorrido recursivo del temario del curso.
      


      

        
function* fibonacci() {
  let anterior = 0, actual = 1;
  while (true) {
    yield anterior;                        // entrega y se congela aquí
    [anterior, actual] = [actual, anterior + actual];
  }
}

tomar(fibonacci(), 12); // solo calcula 12 números

13 Cómo funcionan los módulos ES

      

        La parte central del proyecto: ámbito propio, modo estricto automático, carga diferida,
        evaluación única y enlaces vivos. Todo demostrado en vivo con el código de esta misma página.
      


      

        
Las cinco formas de importar y exportar

        
// ---- Exportar ----
export const NOTA_APROBACION = 4.0;        // nombrada, en línea
export function sumar(...numeros) { }      // nombrada, en línea
export { calcularPromedio as promedio };   // nombrada, con renombrado
export default formatearMoneda;            // por defecto (solo UNA por archivo)

// ---- Importar ----
import { sumar, NOTA_APROBACION } from './modulos/matematicas.js';
import { validarContrasena as revisarClave } from './modulos/validaciones.js';
import precio from './modulos/formato.js';                   // por defecto: el nombre lo eliges tú
import formatearMoneda, { formatearFecha } from './modulos/formato.js'; // por defecto + nombradas
import * as matematicas from './modulos/matematicas.js';
const modulo = await import('./extras/reporte-avanzado.js'); // dinámico

// ⚠️ Las dos líneas del `export default` se muestran juntas solo para comparar
// la sintaxis: en un mismo archivo NO se puede declarar dos veces el mismo
// nombre («Identifier 'formatearMoneda' has already been declared»).


        
Cómo se declara en el HTML

        
<!-- Script CLÁSICO: ámbito global compartido, ejecución inmediata -->
<script src="js/app.js"></script>

<!-- MÓDULO: ámbito propio, modo estricto y carga diferida -->
<script type="module" src="js/main.js"></script>


        
Scripts clásicos frente a módulos ES

        

          

            
              

                Aspecto
                Script clásico
                Módulo ES
              

            
            
              

                Ámbito
                Global compartido: hacía falta una IIFE para no chocar
                Propio de cada archivo: nada se filtra a window
              

              

                Modo estricto
                Opcional, hay que escribir 'use strict'
                Siempre activo, sin escribir nada
              

              

                Momento de ejecución
                Inmediato y bloqueante (salvo defer/async)
                Siempre diferido, como si llevara defer
              

              

                Orden de carga
                El del HTML; hay que ordenar los <script> a mano
                Lo resuelve el grafo de dependencias automáticamente
              

              

                Repetición
                Si lo incluyes dos veces, se ejecuta dos veces
                Se evalúa una sola vez y se cachea (singleton)
              

              

                this en el nivel superior
                window
                undefined
              

              

                Protocolo file://
                Funciona con doble clic
                No funciona: bloqueado por CORS
              

              

                Carga bajo demanda
                No existe de forma nativa
                import() devuelve una promesa

15 Importación dinámica y code splitting

      

        El módulo js/extras/reporte-avanzado.js no se descarga al
        abrir la página. Solo llega cuando pulsas el botón. Eso es dividir el código
        (code splitting) y es la razón de que una aplicación grande arranque rápido.
      


      

        
// import() se escribe como una función y devuelve una PROMESA
boton.addEventListener('click', async () => {
  const modulo = await import('./extras/reporte-avanzado.js');
  const generarReporte = modulo.default;  // la exportación por defecto
  generarReporte(consola);
});


        

          Compruébalo en clase: abre F12 → pestaña Red, recarga la página
          y busca reporte-avanzado.js: no aparece. Pulsa el botón y aparecerá. Pulsa
          otra vez: ya no se vuelve a descargar, sale de la caché de módulos.
