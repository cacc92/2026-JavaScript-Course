1 ¿Qué es el DOM?

Cuando el navegador lee tu HTML no se queda con el texto: construye en memoria un árbol de objetos llamado DOM (Document Object Model). JavaScript no toca el archivo .html; toca ese árbol. Y cada cambio en el árbol se repinta en la pantalla al instante.

El árbol de nodos

  • document
    • <html>
      • <head>
        • <title> → nodo de texto: "06 · DOM"
      • <body>
        • <header>
        • <main>
          • <section> → nodo de texto

Cada caja del árbol es un nodo. Los nodos que son etiquetas se llaman elementos (Element). También hay nodos de texto y nodos de comentario.

window vs document vs Element

ObjetoQué representaEjemplo típico
window La ventana/pestaña del navegador. Es el objeto global. window.innerWidth
document El documento cargado: la raíz del árbol DOM. document.body
Element Una etiqueta concreta dentro del documento. document.querySelector('h1')

Regla mnemotécnica: window es la casa, document es el plano de la casa y cada Element es una habitación.
